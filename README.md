# sean.md

This is my personal site.

It is a small Next.js app for my projects, a bit of writing later on, and the usual personal-site metadata like RSS, sitemap, and Open Graph images.

## Stack

- Next.js
- React
- Tailwind
- Vercel Analytics
- Vercel Speed Insights

## Running locally

```bash
npm install
npm run dev
```

## Notes

- Project content lives in `app/projects/data.ts`.
- The blog exists, but it is intentionally dormant for now.
